# 🚀 功能模块
1. 免费电视源扫描 (freetv)
自动扫描和检测可用的免费电视频道源，对频道链接进行速度检测，并生成可直接用于播放的 M3U 和 TXT 格式列表。支持频道链接可用性检查和 UDP/RTP 链接处理。

输出格式：M3U 播放列表、TXT 文本列表

统计输出：频道速度检测统计文件

最新更新：频道链接速度检测（2026-05-17）

2. 代理 IP 扫描 (proxy)
自动扫描和采集可用的代理 IP 地址，支持代理 IP 的更新和筛选。输出适合代理播放场景的 M3U 格式列表。

输出文件：mg.m3u、mg.txt、ips.txt

更新频率：定期自动扫描更新

最新更新：代理 IP 扫描（2026-05-17）

3. 酒店源 IP 扫描 (Hotel)
专门采集酒店网络环境的 IPTV 源 IP 地址，提供酒店场景下的 IPTV 播放列表。支持频道链接可用性检查和 UDP/RTP 链接处理。

输出格式：IPTV.m3u（M3U 格式）、IPTV.txt（TXT 格式）

频道图标：logo.txt 提供频道图标映射

最新更新：酒店源 IP 更新，增加频道链接可用性检查（2026-05-17）

⚙️ 自动化运行
本项目使用 GitHub Actions 实现自动化扫描和更新：

freetv.yml：免费电视源扫描工作流

hotel_IP_Scanner.yml：酒店源 IP 扫描工作流

proxy_scanner.yml：代理 IP 扫描工作流

工作流定期执行，自动更新各模块的输出文件，并将更新提交到仓库。因此你看到的都是可随时取用的输出结果。

📖 使用方法
获取播放列表
播放列表文件已存放在各模块目录中，你可以直接访问以下链接获取：

模块	M3U 列表	TXT 列表
免费电视源	freetv.m3u	freetv.txt
代理源	mg.m3u	mg.txt
酒店源	IPTV.m3u	IPTV.txt
在播放器中使用
将上述 M3U 链接直接添加到你的 IPTV 播放器中即可：

VLC：媒体 → 打开网络串流 → 粘贴 M3U 链接

PotPlayer：打开链接 → 粘贴 M3U 链接

Kodi：添加视频源 → 选择 M3U 播放列表
